# Настройка Syncthing на двух компьютерах Windows

Syncthing нужно установить отдельно на оба компьютера. В этом хранилище нет программы, паролей, Device ID или готового доступа к другому компьютеру.

Официальная страница загрузки: [Syncthing для Windows](https://syncthing.net/downloads/). Для обычного компьютера Windows подходит **Syncthing Windows Setup** или 64-битная сборка Intel/AMD.

## Что будет синхронизироваться

Теория, задания, ответы ученика, комментарий преподавателя и скрытые разборы находятся в одном файле. Поэтому на обоих компьютерах настраивается одна двусторонняя папка:

| Folder ID | Папка | Тип на обоих компьютерах | Версионирование |
|---|---|---|---|
| `grade9-lessons` | `Занятия` | Send & Receive | Simple File Versioning, 10 версий |

Локальные настройки Obsidian в `.obsidian` не входят в эту папку и через Syncthing не передаются. Правильные ответы оформлены стандартными свёрнутыми блоками Obsidian, поэтому сторонние плагины и CSS не нужны. При первом показе Mermaid-схем Obsidian может попросить разрешение на их отображение; для этого учебного пакета нажмите **Разрешить**.

## 1. Установка и первое открытие

1. Установите Syncthing на обоих компьютерах.
2. Запустите его вручную первый раз и разрешите доступ в окне Брандмауэра Windows для частных сетей.
3. Откройте интерфейс Syncthing. Обычно он доступен по адресу [http://localhost:8384](http://localhost:8384).
4. На каждом компьютере откройте **Actions → Settings → GUI** и задайте отдельные имя пользователя и пароль для локального интерфейса. Не пересылайте эти пароли и не записывайте их в Obsidian.
5. В **Actions → Show ID** посмотрите Device ID каждого компьютера. Подключение должно быть подтверждено с обеих сторон.

## 2. Связать компьютеры

1. На компьютере преподавателя нажмите **Add Remote Device** и вставьте Device ID компьютера ученика. Назовите устройство, например `Ученик`.
2. На компьютере ученика подтвердите запрос и назовите устройство `Преподаватель`.
3. Если автоматический запрос не появился, добавьте Device ID преподавателя вручную через **Add Remote Device**.
4. Проверьте, что оба устройства показываются как подключённые. Передавать Device ID или пароль в заметках не нужно.

## 3. Добавить общую папку на компьютере преподавателя

1. Распакуйте ученическое хранилище и откройте его в Obsidian.
2. В Syncthing нажмите **Add Folder**.
3. Folder Label: `9 класс — занятия`.
4. Folder ID: `grade9-lessons`.
5. Folder Path: полный путь к папке `Занятия` внутри хранилища `9 класс — ученик`.
6. Folder Type: **Send & Receive**.
7. На вкладке Sharing отметьте устройство ученика.
8. На вкладке File Versioning выберите **Simple File Versioning** и укажите 10 версий.
9. Сохраните папку.

## 4. Принять папку на компьютере ученика

1. Примите предложение добавить папку `grade9-lessons`.
2. Folder Path укажите как папку `Занятия` внутри его хранилища `9 класс — ученик`.
3. Folder Type: **Send & Receive**.
4. Включите **Simple File Versioning**, 10 версий.
5. Сохраните и дождитесь статуса **Up to Date**.

Предыдущие версии заменённых или удалённых файлов Syncthing хранит в служебной папке `.stversions`. Не переносите её содержимое вручную в Obsidian.

## 5. Как проходить урок по шагам

1. Откройте нужный урок.
2. Прочитайте теорию, рассмотрите раздел **Наглядная схема** и перейдите к **Тренировке по шагам**.
3. В шаге 1 нажмите `Ctrl+E` и замените строку-подсказку своим ходом решения и ответом.
4. Нажмите на свёрнутый блок **Правильный ответ к шагу 1**, чтобы раскрыть его.
5. Сравните решения и напишите исправление ниже первой попытки.
6. Перейдите к следующему шагу и повторите тот же цикл. Ответы к будущим заданиям заранее не раскрывайте.

Это педагогическое скрытие, а не защита данных: правильное решение находится в том же Markdown-файле и может быть найдено при просмотре исходного текста.

## 6. Автозапуск

Если установлен Windows Setup или приложение в трее, включите запуск вместе со входом в Windows в его настройках. Для базовой сборки можно создать ярлык Syncthing в папке автозагрузки:

1. Нажмите `Win+R` и выполните `shell:startup`.
2. Создайте ярлык на `syncthing.exe` с аргументами `--no-console --no-browser`.
3. После следующего входа в Windows интерфейс останется доступен по адресу `http://localhost:8384`.

## 7. Правила работы без конфликтов

1. Перед открытием урока дождитесь **Up to Date** на обоих компьютерах.
2. Один и тот же урок не редактируют одновременно преподаватель и ученик.
3. После работы закройте заметку и дождитесь **Up to Date** перед выключением компьютера.
4. Новые уроки добавляйте отдельными файлами. Не заменяйте архивом всё хранилище после того, как ученик начал отвечать.
5. Если появился файл с `sync-conflict` в названии, не удаляйте его: сравните обе версии и перенесите нужный текст в основной файл.
6. Syncthing синхронизирует изменения и удаления, поэтому он не заменяет резервную копию. Версионирование помогает восстановить предыдущую копию.
7. Не подключайте OneDrive, Obsidian Sync или другую службу синхронизации к этой же папке.

## 8. Контрольная проверка

1. Преподаватель создаёт в `Занятия` файл `Проверка передачи.md` и ждёт **Up to Date**.
2. Ученик проверяет появление файла, добавляет в него строку `Ответ ученика` и ждёт **Up to Date**.
3. Преподаватель проверяет, что строка появилась у него.
4. Преподаватель удаляет тестовый файл, оба компьютера снова должны показать **Up to Date**.

Если устройства не подключаются, сначала проверьте: Syncthing запущен на обоих компьютерах, Device ID подтверждены, интернет доступен, а Брандмауэр Windows разрешил Syncthing.
