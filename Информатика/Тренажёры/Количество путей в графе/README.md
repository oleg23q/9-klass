# Количество путей в графе — интерактивный тренажёр

Автономный веб-тренажёр к уроку [[Урок 06 - Пути в графе и количество путей]]. Продолжает [[../Графы и матрицы/README|тренажёр «Графы и матрицы»]] и разбирает с нуля, что такое путь и как считать их количество. Формат прежних тренажёров: краткая теория, управляемая модель, пошаговые разборы, алгоритм с проверкой перечислением и задания с мгновенной проверкой.

## Запуск

Откройте файл [index.html](index.html) в современном браузере. Интернет, установка и сервер не нужны.

## Разделы

- **Теория** — путь и длина пути, правила умножения и сложения, метод подписей у вершин, пути через вершину и не через неё, неориентированный граф.
- **Эксперимент** — на экране граф; нужно подписать вершины числом путей из старта. Проверка отмечает верные и неверные подписи, подсказка показывает, какие стрелки входят в вершину, но не само число. Четыре графа.
- **Разборы задач** — четыре подробные задачи с рисунками; шаги открываются по одному.
- **Проверка перечислением** — выбор графа, список всех путей, сравнение с методом подписей, подсчёт путей через выбранную вершину и не через неё.
- **Задания** — двадцать задач с графами, подсказкой и полным разбором после первой попытки; результат сохраняется только в браузере.

## Учебный порядок

1. Пройти объяснение в уроке 06 (после него — урок 07 «Графы по таблице» и тренажёр [[../Кратчайший путь по таблице/README|«Кратчайший путь по таблице»]]).
2. В эксперименте подписать вершины первого графа, затем остальных; проверить перечислением.
3. Разобрать задачи.
4. Решить задания 1–20; после ошибки открыть подсказку, затем разбор и повторить.

Модель рассматривает ориентированные графы без циклов и простые пути без повторения вершин в неориентированном графе. Готовый тренажёр не доказывает, что занятие проведено или тема освоена.
