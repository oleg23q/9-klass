Кратчайший путь по таблице

Интерактивный тренажёр · 9 класс · Информатика · Урок 07

Главная идея

Сначала нарисуй граф по таблице, потом решай

В таблице дорог число на пересечении строки и столбца — длина дороги между двумя городами, пустая клетка — дороги нет. Длина пути — сумма весов. Количество путей — это перебор, и веса в нём не складывают. Условие «через пункт» делит путь на два куска, а «не через пункт» вычёркивает пункт из графа.

длина = w₁ + w₂ + … d(X) = min(d(Y) + w) через X: d(А→X) + d(X→Ф)
01

Читаем таблицу

Строка — один город, столбец — другой. Число в клетке — дорога между ними, пустая клетка — дороги нет. Таблица зеркальна: граф неориентированный. Рёбра читай выше диагонали, чтобы не записать дорогу дважды.

02

Длина или количество

Длина пути А→Б→Г — сумма весов. Количество путей — сколько разных последовательностей вершин ведут из А в Г; веса не используют. Вершины в пути не повторяются.

03

Кратчайший путь

Выпиши пути и сложи веса или подпиши вершины расстояниями: d(А) = 0, а для остальных d(X) = минимум из d(Y) + w по подписанным соседям. Подписывай в порядке возрастания расстояния.

04

Через и не через

Через X: кратчайший путь А→X плюс кратчайший X→Ф. Не через X: вычеркни X и его дороги и решай обычную задачу. Количество путей с запретом считай так же.

Не путай: если спрашивают «сколько путей», сумма весов не нужна и ответом быть не может. Если спрашивают «длину кратчайшего пути», нужна сумма весов.
Управляемая модель

Подпиши вершины кратчайшими расстояниями

неориентированный граф с весами
Подписывай по порядку возрастания расстояния: d(X) — минимум из d(Y) + вес дороги Y—X по уже подписанным соседям.
Впиши расстояния и нажми «Проверить». Если вершину нельзя достичь, напиши 0 только у источника, а у недостижимых оставь прочерк «-».
