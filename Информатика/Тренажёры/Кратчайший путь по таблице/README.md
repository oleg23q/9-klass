# Кратчайший путь по таблице — интерактивный тренажёр

Автономный веб-тренажёр к уроку [[Урок 07 - Графы по таблице]]. Продолжает [[../Количество путей в графе/README|тренажёр «Количество путей в графе»]] и разбирает задачи, в которых граф задан таблицей дорог: длина пути, кратчайший путь, обязательный и запрещённый пункт, количество путей.

## Запуск

Откройте файл [index.html](index.html) в современном браузере. Интернет, установка и сервер не нужны.

## Разделы

- **Теория** — как читать таблицу, длина и количество путей, кратчайший путь, «через» и «не через» пункт.
- **Расстояния** — таблица и граф с весами; нужно подписать вершины кратчайшими расстояниями. Можно выбрать таблицу, начало и запрещённый пункт. Подсказка показывает расчёт по соседям, но не готовый ответ.
- **Разборы задач** — четыре подробные задачи (чтение таблицы, длина и количество, кратчайший путь, запрещённый пункт); шаги открываются по одному.
- **Все пути** — выбранные таблица, начало и конец, условие; тренажёр выписывает все пути с длинами, кратчайший и количество.
- **Задания** — шестнадцать задач с таблицами, подсказкой и полным разбором после первой попытки; рисунок графа открывается кнопкой. Результат сохраняется только в браузере.

## Учебный порядок

1. Пройти урок 07.
2. Подписать расстояния в нескольких таблицах, затем с запрещённым пунктом.
3. Проверить результаты перебором всех путей.
4. Разобрать задачи и решить задания 1–16; после ошибки открыть подсказку, затем разбор и повторить.

Модель рассматривает неориентированные графы и простые пути без повторения вершин. Задания написаны по образцу заданий ОГЭ, но не являются копиями официальных вариантов. Готовый тренажёр не доказывает, что занятие проведено или тема освоена.
