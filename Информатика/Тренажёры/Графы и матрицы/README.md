# Графы и матрицы — интерактивный тренажёр

Автономный веб-тренажёр к уроку [[Урок 05 - Знаковые и табличные модели. Графы и матрицы]].

## Запуск

Откройте файл [index.html](index.html) в современном браузере. Сборка и установка не нужны.

## Разделы

- теория о графах, матрицах смежности и весовых матрицах;
- генератор графов с матрицей для заполнения;
- подсказка и пошаговое решение;
- интерактивная демонстрация алгоритма;
- шесть типовых заданий по теме графов и путей в разделе ОГЭ;
- отдельная ступень из четырёх задач повышенной сложности в стиле ЕГЭ: динамический подсчёт путей, маршрут с условием и кратчайший путь через заданную вершину.

## Учебный порядок

1. Пройти объяснение в уроке.
2. Решить по одной задаче на неориентированный невзвешенный и взвешенный граф.
3. Решить одну задачу на ориентированный граф.
4. Выполнить задания 1, 2 и 5 в разделе ОГЭ.
5. После уверенного решения ОГЭ перейти во вкладку «ЕГЭ — сложнее» и решить задачи 1–4 методом подписей у вершин.

Задачи повышенной сложности являются учебными задачами в стиле ЕГЭ, а не копиями официального банка заданий.

`0` вне диагонали в задачах тренажёра означает отсутствие прямого ребра. Диагональные нули относятся к рассматриваемым простым графам без петель.
