Вариант А

Задание 1. Ответ: параметр: number; аргументы: 6 и 10; вывод: 12; 20

Назови параметр, два аргумента и значения, которые выведет программа.
  • Параметр — имя в определении (number), аргументы — значения при вызове.
  • Вывод: 12; 20
Частые неверные ответы и ошибки: параметр назван значением 6 — П: перепутаны параметр и аргумент

Задание 2. Ответ: x = 7; вывод 7

Запиши значения переменных после выполнения: что окажется в x и что выведет программа?
  • Функция складывает аргументы 2 и 5 и возвращает 7; значение записывается в x.
Частые неверные ответы и ошибки: x = None — П: не учтён return

Задание 3. Ответ: 13

Что выведет программа и почему?
  • Сначала вычисляется значение вызова функции, затем арифметика с результатом.
Частые неверные ответы и ошибки: ошибка вместо числа — К: результат return можно использовать в выражении

Задание 4. Ответ: нет двоеточия после def; нет отступа у return

Найди две ошибки и запиши правильный вариант.
  • Две ошибки: пропущено двоеточие после заголовка и нет отступа у строки return.
  • Правильно: def cube(number): ⏎ return number * number * number ⏎ ⏎ print(cube(3))
  • Вывод: 27
Частые неверные ответы и ошибки: найдена только одна ошибка — К: нужно проверить заголовок и отступ

Задание 5. Ответ: 14

Напиши функцию perimeter(a, b), которая возвращает периметр прямоугольника со сторонами a и b. Вызови её для сторон 5 и 2 и выведи результат.
  • Функция: def perimeter(a, b): return ...; вызов print(perimeter(5, 2)) выводит 14.
Частые неверные ответы и ошибки: print внутри функции вместо return — П: функция печатает, но не возвращает значение

Задание 6. Ответ: 16; None

Что выведет программа? Объясни результат.
  • Функция печатает число внутри себя, но ничего не возвращает: значение переменной value — None.
  • Вывод: 16; None
Частые неверные ответы и ошибки: только число без None — П: не учтено, что функция без return возвращает None

Задание 7. Ответ: параметр — имя для данных в определении; аргумент — значение при вызове; return возвращает результат в основную программу; нужен return

Закончи фразу: «Параметр — это ..., аргумент — это ..., а return ...». Что нужно выбрать внутри функции, если результат нужен для дальнейшего вычисления: print или return?
  • return передаёт результат в место вызова, print только показывает его на экране.
Частые неверные ответы и ошибки: выбран print — П: print не возвращает значение для дальнейшего вычисления
