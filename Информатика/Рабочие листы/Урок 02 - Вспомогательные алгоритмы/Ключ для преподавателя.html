Вариант А

Задание 1. Ответ: печать строки «-----»

В алгоритме найди действие, которое повторяется.
  • Повторяется одна и та же строка вывода; её удобно оформить как вспомогательный алгоритм.
Частые неверные ответы и ошибки: называется команда с названием меню — П: перепутано повторяющееся действие и обычная строка

Задание 2. Ответ: например: line и separator; понятные английские слова без пробелов

Придумай два понятных имени для вспомогательного алгоритма, который печатает «===».
  • Имя описывает действие или результат; без пробелов; удобно читать в программе.
Частые неверные ответы и ошибки: имя, например, «моя функция 1» — К: в имени пробел или непонятное имя

Задание 3. Ответ: Привет; Привет; Конец

Что выведет программа?
  • Определение функции ничего не печатает. Вызовы выполняются по порядку; результат: Привет; Привет; Конец.
Частые неверные ответы и ошибки: вывод без повторов — Т: не учтено, что каждый вызов функции выполняет её заново; вывод слова из определения без вызова — К: перепутаны определение и вызов

Задание 4. Ответ: ошибка в отступе: тело функции записывается с отступом

Почему программа не запускается? Запиши исправленный вариант.
  • Тело функции после двоеточия записывается с отступом (4 пробела).
  • Исправленный вариант: def line(): ⏎ print("-----") ⏎ ⏎ line()
Частые неверные ответы и ошибки: «нет двоеточия» — К: двоеточие в программе есть, проверь отступ

Задание 5. Ответ: определение: def star(): print(...); вызов: star()

Укажи, где функция определяется, а где вызывается.
  • Определение начинается со слова def и содержит тело функции; вызов — строка с именем и скобками вне определения.
Частые неверные ответы и ошибки: вызов назван определением — П: перепутаны определение и вызов

Задание 6. Ответ: ===; Python; ===; Алгоритмы; ===

Напиши функцию separator() так, чтобы программа вывела пять строк: ===, Python, ===, Алгоритмы, === (по порядку).
  • Определить функцию с print("===") и вызвать её три раза между остальными строками.
Частые неверные ответы и ошибки: функция не вызвана — К: определение без вызова ничего не печатает

Задание 7. Ответ: помогает не повторять код; def создаёт функцию; line — имя, line() — запуск функции

Объясни: зачем нужен вспомогательный алгоритм, что делает def и чем имя line отличается от вызова line().
  • Вспомогательный алгоритм убирает повторы и делает программу короче и понятнее.
  • def определяет функцию, но не запускает её.
  • line — имя функции, line() — вызов.
Частые неверные ответы и ошибки: def запускает функцию — П: перепутаны определение и запуск

Лист В: усложнённые задания

Задание 1. Ответ: 25; 20

Что выведет программа? Запиши два числа и объясни порядок вызовов.
  • sum_sq(3, 4) → sq(3) + sq(4) = 9 + 16 = 25.
  • sum_sq(2, sq(2)): сначала sq(2) = 4, затем sq(2) + sq(4) = 4 + 16 = 20.
Частые неверные ответы и ошибки: 25 и 8 — Т: вложенный вызов sq(2) не вычислен до вызова sum_sq

Задание 2. Ответ: 6 раз; two — 3 раза, step — 6 раз

Сколько раз будет выведено слово «шаг»? Сколько всего раз вызывается каждая функция?
  • Цикл вызывает two() 3 раза, каждая two() вызывает step() 2 раза: 3 · 2 = 6.
Частые неверные ответы и ошибки: 3 — Т: не учтены два вызова step внутри two; 2 — Т: не учтён цикл

Задание 3. Ответ: +++++; |; +++++; ++; |; ++

Что выведет программа?
  • frame(5): +++++, |, +++++; frame(2): ++, |, ++.
  • Параметры w и c разные для каждого вызова.
Частые неверные ответы и ошибки: +++++ без остальных строк — Т: не учтены три вызова mark внутри frame

Задание 4. Ответ: def box(text): ⏎ line = '-' * (len(text) + 4) ⏎ print(line) ⏎ print('| ' + text + ' |') ⏎ print(line) ⏎ box('Python') ⏎ box('Граф') ⏎ box('Матрица')

Нужно напечатать три одинаковые «рамки» вокруг слов «Python», «Граф» и «Матрица». Напиши вспомогательный алгоритм с параметром и основную часть, не повторяя код трижды. Объясни выигрыш.
  • Повторяющиеся три строки выносятся в функцию с параметром text.
  • Выигрыш: код короче, ошибку исправляют в одном месте.
Частые неверные ответы и ошибки: три копии одного кода — Л: вспомогательный алгоритм не использован
