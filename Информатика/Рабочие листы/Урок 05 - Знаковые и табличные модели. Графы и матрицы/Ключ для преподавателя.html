Вариант А

Задание 1. Ответ: словесная; математическая; графическая; табличная; алгоритмическая

Определи вид модели: описание погоды словами; формула площади прямоугольника; схема автобусов; таблица дежурств; инструкция по эвакуации.
  • Словесная, математическая, графическая, табличная, алгоритмическая — по тому, какими знаками записана модель.
Частые неверные ответы и ошибки: все модели названы табличными — П: не различает виды знаковых моделей

Задание 2. Ответ: объекты — устройства в строках (Ноутбук A, Ноутбук B, Планшет C); свойства — столбцы: цена, масса, память

В таблице назови объекты и свойства: что стоит в строках, а что в столбцах?
  • Объекты — отдельные предметы в строках, свойства — названия столбцов.
Частые неверные ответы и ошибки: объекты и свойства поменяны местами — П: объект — то, что описывают, свойство — чем описывают

Задание 3. Ответ: A—B, B—C; ребра A—C нет

Прочитай двоичную матрицу неориентированного графа. Какие рёбра есть? Есть ли ребро между A и C?
  • Единица в строке X и столбце Y означает ребро X—Y.
  • Рёбра: A—B, B—C
Частые неверные ответы и ошибки: названы ячейки, а не рёбра — Ч: не переведена матрица в граф; ребро названо существующим при нулевой клетке — Ч: не проверена клетка

Задание 4. Ответ: 0 1 0 | 1 0 1 | 0 1 0

Построй двоичную матрицу для неориентированного графа с рёбрами A—B, B—C. Порядок вершин: A, B, C.
  • На диагонали нули, каждое ребро даёт две симметричные единицы.
Частые неверные ответы и ошибки: единицы только в одной половине — Н: не учтена симметрия неориентированного графа

Задание 5. Ответ: 0 5 0 | 5 0 3 | 0 3 0

Построй весовую матрицу по дорогам: A—B = 5, B—C = 3. Нет прямой дороги — запиши 0.
  • Вместо единицы записывается вес, диагональ нулевая, матрица симметрична.
Частые неверные ответы и ошибки: единицы вместо весов — П: перепутаны двоичная и весовая матрицы

Задание 6. Ответ: 0 1 0 | 0 0 0 | 1 0 0

Построй двоичную матрицу ориентированного графа с дугами A→B, C→A (строка — откуда, столбец — куда).
  • Каждая дуга даёт одну единицу: в строке начала и в столбце конца.
Частые неверные ответы и ошибки: добавлены обратные единицы — Н: ориентированный граф сделан симметричным

Задание 7. Ответ: в неориентированном графе ребро действует в обе стороны, поэтому обе клетки равны 1; у дуги A→B обратной дуги нет, поэтому матрица может быть несимметричной

Почему в матрице неориентированного графа значения в клетках AB и BA одинаковы? Может ли быть так в ориентированном?
  • Неориентированное ребро заполняет обе зеркальные клетки.
  • Дуга A→B заполняет только клетку AB; симметрия возникает, только если у каждой дуги есть обратная.
Частые неверные ответы и ошибки: «симметрия есть всегда» — Н: не различает ориентированный и неориентированный граф
