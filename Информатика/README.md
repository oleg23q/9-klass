# Информатика

Этот раздел для алгоритмов, программирования, логики, таблиц, баз данных, сетей, квизов и повторения информатики 9 класса.

## Что хранить здесь

- конспекты по темам;
- задачи ОГЭ и школьные задачи;
- программы и разборы алгоритмов;
- таблицы трассировки;
- ошибки ученика и исправленные решения;
- проверочные работы и ответы.

## Основные темы

- кодирование информации и единицы измерения;
- логика и таблицы истинности;
- алгоритмы, ветвления, циклы;
- программирование на Python или языке школы;
- электронные таблицы;
- базы данных;
- сети и цифровая безопасность.

## Быстрый запуск

```text
$grade9-informatics-tutor объясни циклы Python для 9 класса и дай 10 задач от простых к сложным
```

```text
$grade9-informatics-tutor проверь программу ученика, найди ошибку и объясни на примере
```

```text
$grade9-informatics-tutor сделай тренировку по логике и таблицам истинности
```
