## Новое понятие: условие

Условие - это выражение, на которое можно ответить "да" или "нет".

Примеры условий:

```text
число больше 0
возраст не меньше 14
пароль равен правильному паролю
```

В Python условия записываются через знаки сравнения.

| Математика | Python | Как читать |
| --- | --- | --- |
| больше | `>` | больше |
| меньше | `<` | меньше |
| больше или равно | `>=` | не меньше |
| меньше или равно | `<=` | не больше |
| равно | `==` | равно |
| не равно | `!=` | не равно |

Важно:

```python
x = 5
```

Это присваивание: запомнить значение `5` в переменной `x`.

```python
x == 5
```

Это сравнение: проверить, равно ли `x` числу `5`.

## Конструкция `if`

`if` переводится как "если".

Общий вид:

```python
if условие:
    действие
```

Пример:

```python
x = int(input("Введите число: "))

if x > 0:
    print("Число положительное")
```

Если `x > 0` верно, программа напечатает текст.

Если `x > 0` неверно, программа ничего не напечатает.

## Важная деталь: отступы

В Python отступ показывает, какая команда относится к `if`.

Правильно:

```python
if x > 0:
    print("Число положительное")
```

Неправильно:

```python
if x > 0:
print("Число положительное")
```

После строки с `if` нужен двоеточие `:`, а следующая команда пишется с отступом.

## `else`: иначе

Часто нужно выбрать одно из двух действий.

```python
if условие:
    действие если условие верно
else:
    действие если условие неверно
```

Пример:

```python
age = int(input("Введите возраст: "))

if age >= 14:
    print("Можно получить паспорт")
else:
    print("Пока рано")
```

## Разбор примера

Задача:

> Дано число. Определить, положительное оно или не положительное.

### Шаг 1. Что дано?

Дано одно число `x`.

### Шаг 2. Что нужно получить?

Нужно вывести:

- `Положительное`, если число больше 0;
- `Не положительное`, если число не больше 0.

### Шаг 3. Алгоритм словами

1. Ввести число.
2. Проверить, больше ли число нуля.
3. Если да, вывести `Положительное`.
4. Иначе вывести `Не положительное`.

### Шаг 4. Программа

```python
x = int(input("Введите число: "))

if x > 0:
    print("Положительное")
else:
    print("Не положительное")
```

### Шаг 5. Проверка на примерах

| Входное число | Условие `x > 0` | Что выведет программа |
| --- | --- | --- |
| `5` | верно | `Положительное` |
| `-3` | неверно | `Не положительное` |
| `0` | неверно | `Не положительное` |

Важно проверить `0`, потому что это пограничный случай.

## Мини-трассировка

Для входа `x = -2`:

| Шаг | Действие | x | Результат |
| --- | --- | --- | --- |
| 1 | вводим число | -2 | - |
| 2 | проверяем `x > 0` | -2 | неверно |
| 3 | выполняется ветка `else` | -2 | вывод `Не положительное` |

## Вторая программа: четное или нечетное

Чтобы проверить четность, используют остаток от деления.

```python
n = int(input("Введите число: "))

if n % 2 == 0:
    print("Четное")
else:
    print("Нечетное")
```

Объяснение:

- `n % 2` - остаток от деления `n` на 2;
- если остаток равен `0`, число четное;
- если остаток не равен `0`, число нечетное.

Проверка:

| n | `n % 2` | Вывод |
| --- | --- | --- |
| 8 | 0 | `Четное` |
| 7 | 1 | `Нечетное` |

## Как реагировать на ошибки

Если ученик пишет `=` вместо `==`:

> Один знак `=` записывает значение. Два знака `==` задают вопрос: "равно ли?"

Если ученик забывает двоеточие:

> После условия ставим двоеточие, потому что дальше начинается блок команд.

Если ученик не делает отступ:

> Отступ показывает, какие команды выполняются внутри `if`.

Если ученик не проверяет ноль:

> В задачах с числами часто нужно отдельно думать про границу: 0, 1, -1, ровно 100.
