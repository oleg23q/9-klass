## Объяснение темы

### Алгоритм

Алгоритм - это точное описание шагов, которые приводят к результату.

Признаки хорошего алгоритма:

- шаги понятны исполнителю;
- шаги идут в правильном порядке;
- после выполнения получается нужный результат;
- нет лишних или невозможных команд.

### Исполнитель

Исполнитель - тот, кто выполняет команды.

Примеры:

- человек;
- робот;
- компьютерная программа;
- черепашка/исполнитель в школьной среде.

Важно: исполнитель не "догадывается", а выполняет только понятные ему команды.

### Команда

Команда - один конкретный шаг алгоритма.

Плохая команда:

```text
Сделай красиво.
```

Почему плохо: непонятно, что именно делать.

Хорошая команда:

```text
Нарисуй квадрат со стороной 4 клетки.
```

Почему хорошо: действие конкретное и проверяемое.

## Главная схема задач

Любую простую задачу можно разложить так:

```text
входные данные -> обработка -> результат
```

Пример:

```text
два числа -> сложить их -> сумма
```

## Разбор примера

Задача:

> Даны два числа. Найти их сумму и произведение.

### Шаг 1. Что дано?

Даны два числа: `a` и `b`.

### Шаг 2. Что нужно получить?

Нужно получить:

- сумму `a + b`;
- произведение `a * b`.

### Шаг 3. Алгоритм словами

1. Ввести первое число.
2. Ввести второе число.
3. Найти сумму.
4. Найти произведение.
5. Вывести сумму.
6. Вывести произведение.

### Шаг 4. Программа на Python

```python
a = int(input())
b = int(input())

summa = a + b
product = a * b

print(summa)
print(product)
```

Пояснение:

- `input()` получает данные;
- `int(...)` превращает введенный текст в число;
- `=` запоминает значение в переменной;
- `print(...)` выводит результат.

### Шаг 5. Трассировка

Проверим программу на числах `3` и `5`.

| Шаг | Действие | a | b | summa | product | Вывод |
| --- | --- | --- | --- | --- | --- | --- |
| 1 | ввели `a` | 3 | - | - | - | - |
| 2 | ввели `b` | 3 | 5 | - | - | - |
| 3 | `summa = a + b` | 3 | 5 | 8 | - | - |
| 4 | `product = a * b` | 3 | 5 | 8 | 15 | - |
| 5 | `print(summa)` | 3 | 5 | 8 | 15 | 8 |
| 6 | `print(product)` | 3 | 5 | 8 | 15 | 15 |

Вывод программы:

```text
8
15
```

## Ответы для преподавателя

### Диагностика

1. Результат: вода закипела / чайник вскипятил воду.
2. Потому что другой порядок может дать другой результат или вообще не сработать.
3. Взять хлеб -> намазать масло -> положить сыр.
4. `x = 7`.
5. Входные данные: два числа. Результат: их сумма.

### Практика

Задание 1:

- входные данные: стороны `a` и `b`;
- обработка: вычислить `2 * (a + b)`;
- результат: периметр.

Задание 2:

1. ввести первое число;
2. ввести второе число;
3. найти сумму;
4. вывести ответ.

Задание 3:

| Шаг | x | y |
| --- | --- | --- |
| после `x = 4` | 4 | - |
| после `y = x + 3` | 4 | 7 |
| после `x = y * 2` | 14 | 7 |

Задание 4, пример:

1. Ввести первую оценку.
2. Ввести вторую оценку.
3. Сложить оценки.
4. Разделить сумму на 2.
5. Вывести среднее.

Задание 5:

Ошибка в строке:

```python
summa = a * b
```

Нужно сложение:

```python
summa = a + b
```

## Как реагировать на ошибки

Если ученик путает `=` с "равно" из математики:

> В программировании `=` значит "запомнить значение справа в переменную слева".

Если ученик не понимает, почему `x` изменился:

> Переменная похожа на коробку с наклейкой. Если положили новое значение, старое заменилось.

Если ученик пишет код до разбора задачи:

> Сначала три строки в тетради: что дано, что найти, какие действия. Потом код.
