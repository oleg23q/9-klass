# Общий раздел

Этот раздел для общего учебного управления по 9 классу: цели, расписание, диагностика, повторение и контроль прогресса по физике, химии и информатике.

## Что хранить здесь

- недельные и месячные планы занятий;
- результаты диагностических тестов;
- расписание интервальных повторений;
- список слабых тем;
- общий журнал прогресса.

## Быстрый запуск

```text
$grade9-study-coach составь план занятий на неделю по физике, химии и информатике для ученика 9 класса
```

```text
$grade9-study-coach проведи диагностический тест: 5 вопросов по физике, 5 по химии, 5 по информатике
```

```text
$grade9-study-coach сделай расписание повторения на месяц по темам, где ученик ошибается
```
