# Q: Какие существующие материалы связаны с первыми тремя уроками физики и как сохранить их последовательность при дополнении?

## Answer

Полезный маршрут найден: учительские уроки 01-03 связаны с ученическими копиями тренажёра; последовательность сохраняется как система отсчёта, затем путь и перемещение, затем равномерное прямолинейное движение. Дополнения внесены в обе линии материалов без добавления четвёртого урока.
