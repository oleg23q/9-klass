# 9 КЛАСС

## Учебное приложение

Добавлен отдельный Windows-тренажёр на C#/.NET: [9 КЛАСС — Тренажёр](Grade9Trainer/README.md). Приложение читает ученические Markdown-уроки, сохраняет ответы отдельно и позволяет добавлять новые уроки без пересборки. Готовая Windows-сборка опубликована в [релизе MVP от 6 сентября 2026 года](https://github.com/oleg23q/9-klass/releases/tag/trainer-mvp-2026-09-06).

Учебный проект для системной подготовки ученика 9 класса по физике, химии и информатике.

## Назначение

Репозиторий хранит материалы для регулярных занятий:

- планы и диагностику по всем предметам;
- конспекты и сценарии уроков;
- практические задания;
- домашние задания;
- ответы и разборы типичных ошибок.

## Структура

- `Общий/` - общие планы, диагностика, повторение и контроль прогресса.
- `Физика/` - темы, формулы, задачи и проверочные материалы по физике.
- `Химия/` - уроки, реакции, расчеты и задания по химии.
- `Информатика/` - алгоритмы, программирование, логика, таблицы и задачи ОГЭ.

## Как вести проект

1. Новые уроки добавлять в папку соответствующего предмета.
2. В начале каждого урока фиксировать цель, время и стартовый уровень ученика.
3. После занятия дописывать ошибки, которые нужно повторить позже.
4. Общий прогресс и расписание повторения хранить в `Общий/`.

## Быстрый старт

Для начала работы с учеником открыт [стартовый запас уроков физики и химии](Общий/Стартовый%20запас%20-%20физика%20и%20химия.md). Физика дополнена проверочной работой по кинематике, тремя уроками динамики — об инерции, законах Ньютона и свободном падении — и двумя уроками о прямолинейном и криволинейном движении и движении по окружности; к каждому из них добавлены автономный веб-тренажёр, четыре разобранные задачи и двенадцать заданий с разбором. В химии после четырёх стартовых тем подготовлен урок 05 по окислительно-восстановительным реакциям со степенями окисления, электронным балансом и автономным веб-тренажёром. В материалах есть сценарии, практика, домашние задания, ключи и критерии перехода; результаты занятий ещё не зафиксированы.

По информатике подготовлены пять активных уроков: четыре по стартовой последовательности Босовой и отдельный тематический модуль «Знаковые и табличные модели. Графы и матрицы» с автономным веб-тренажёром. Они находятся в [разделе информатики](Информатика/README.md); занятия и прогресс ученика ещё не подтверждены.

Для планирования занятий:

```text
$grade9-study-coach составь план занятий на неделю по физике, химии и информатике для ученика 9 класса
```

Для предметной тренировки:

```text
$grade9-physics-tutor сделай тренировку по законам Ньютона
$grade9-chemistry-tutor составь квиз по коэффициентам в уравнениях реакций
$grade9-informatics-tutor дай задачи на условия if для 9 класса
```
