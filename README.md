# 9 КЛАСС

Учебный проект для системной подготовки ученика 9 класса по физике, химии и информатике.

## Назначение

Репозиторий хранит материалы для регулярных занятий:

- планы и диагностику по всем предметам;
- конспекты и сценарии уроков;
- практические задания;
- домашние задания;
- ответы и разборы типичных ошибок.

## Структура

- `Общий/` - общие планы, диагностика, повторение и контроль прогресса.
- `Физика/` - темы, формулы, задачи и проверочные материалы по физике.
- `Химия/` - уроки, реакции, расчеты и задания по химии.
- `Информатика/` - алгоритмы, программирование, логика, таблицы и задачи ОГЭ.

## Как вести проект

1. Новые уроки добавлять в папку соответствующего предмета.
2. В начале каждого урока фиксировать цель, время и стартовый уровень ученика.
3. После занятия дописывать ошибки, которые нужно повторить позже.
4. Общий прогресс и расписание повторения хранить в `Общий/`.

## Быстрый старт

Для планирования занятий:

```text
$grade9-study-coach составь план занятий на неделю по физике, химии и информатике для ученика 9 класса
```

Для предметной тренировки:

```text
$grade9-physics-tutor сделай тренировку по законам Ньютона
$grade9-chemistry-tutor составь квиз по коэффициентам в уравнениях реакций
$grade9-informatics-tutor дай задачи на условия if для 9 класса
```
