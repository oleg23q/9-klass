# Химия

Этот раздел для реакций, уравнений, расчетов, ионных уравнений, квизов и повторения химии 9 класса.

## Что хранить здесь

- конспекты по темам;
- уравнения реакций;
- расчеты по химическим формулам;
- таблицы кислот, оснований, солей;
- ошибки ученика и разборы;
- проверочные работы и ответы.

## Уроки

- [Урок 01. Язык химии: формулы, индексы, коэффициенты](Уроки/Урок%2001%20-%20Язык%20химии.md)

## Основные темы

- химические уравнения и расчеты;
- электролитическая диссоциация;
- ионные реакции;
- окислительно-восстановительные реакции;
- оксиды, кислоты, основания, соли;
- металлы и неметаллы;
- периодический закон.
