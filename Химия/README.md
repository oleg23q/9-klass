# Химия

Этот раздел для реакций, уравнений, расчетов, ионных уравнений, квизов и повторения химии 9 класса.

## Что хранить здесь

- конспекты по темам;
- уравнения реакций;
- расчеты по химическим формулам;
- таблицы кислот, оснований, солей;
- ошибки ученика и разборы;
- проверочные работы и ответы.

- [Урок 02. Классификация химических реакций](Уроки/Урок%2002%20-%20Классификация%20химических%20реакций.md)

Готовы три основных занятия по 45 минут и отдельная подготовка 00. [Порядок запуска и критерии перехода](../Общий/Стартовый%20запас%20-%20физика%20и%20химия.md). Проведение уроков и освоение проверяются по ответам ученика.

## Учебник учителя

По фото ориентир: О. С. Габриелян, И. Г. Остроумов, С. А. Сладков, "Химия. 9 класс", Просвещение.

Для занятий дома: если учитель дал конкретный параграф, сначала делаем урок по этому параграфу, а подготовительные материалы используем как разминку или восстановление базы.

## Основные темы

- химические уравнения и расчеты;
- электролитическая диссоциация;
- ионные реакции;
- окислительно-восстановительные реакции;
- оксиды, кислоты, основания, соли;
- металлы и неметаллы;
- периодический закон.
