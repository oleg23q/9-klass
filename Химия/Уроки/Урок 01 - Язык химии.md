# Урок 01. Язык химии: формулы, индексы, коэффициенты

## Для кого

Ученик только начинает 9 класс. Урок не проверочный, а вводный: спокойно восстановить базу, без оценивания и давления.

## Цели урока

К концу урока ученик должен:

- понимать, что показывает химическая формула;
- отличать индекс от коэффициента;
- считать атомы в простых и сложных формулах;
- понимать, что химическое уравнение нужно уравнивать;
- расставлять коэффициенты в простых реакциях.

## План на 45-60 минут

| Этап | Время | Что делаем |
|---|---:|---|
| 1. Входной разговор | 5 минут | Выясняем, что ученик помнит: формулы, реакции, коэффициенты |

## 1. Входной разговор

Сначала не спрашиваем "что ты не знаешь?". Лучше спросить мягко:

- Что такое химическая формула?
- Чем отличается H2 от 2H?
- Можно ли в формуле менять маленькие цифры?
- Зачем ставят коэффициенты перед формулами?

Если ученик отвечает неуверенно, это нормально. Значит, урок надо вести с самого начала.

## 2. Как читать химическую формулу

Химическая формула показывает:

- какие элементы входят в вещество;
- сколько атомов каждого элемента содержится в одной частице вещества.

Примеры:

| Формула | Как читаем | Состав |
|---|---|---|
| H2O | аш-два-о | 2 атома H и 1 атом O |
| CO2 | цэ-о-два | 1 атом C и 2 атома O |
| NaCl | натрий-хлор | 1 атом Na и 1 атом Cl |
| CaCO3 | кальций-цэ-о-три | 1 Ca, 1 C, 3 O |

Важное правило: если после символа элемента нет маленькой цифры, значит там 1 атом.

Пример:

```text
CO2
C = 1 атом
O = 2 атома
```

## 3. Скобки в формулах

Если в формуле есть скобки, индекс после скобки умножает все, что внутри скобок.

Пример:

```text
Al2(SO4)3
Al = 2
S = 1 * 3 = 3
O = 4 * 3 = 12
```

Итого в Al2(SO4)3:

- 2 атома алюминия;
- 3 атома серы;
- 12 атомов кислорода.

## 4. Индекс и коэффициент

Это одна из самых частых ошибок.

**Индекс** - маленькая цифра внутри формулы. Он показывает состав вещества.

```text
H2O
```

Здесь индекс 2 относится только к водороду.

**Коэффициент** - большая цифра перед формулой. Он показывает количество частиц вещества.

```text
2H2O
```

Здесь коэффициент 2 означает две молекулы воды.

Считаем атомы:

```text
2H2O
H = 2 * 2 = 4 атома
O = 2 * 1 = 2 атома
```

Главное правило: при уравнивании реакций можно менять коэффициенты, но нельзя менять индексы в формулах.

Почему нельзя менять индексы:

```text
H2O  - вода
H2O2 - перекись водорода, другое вещество
```

Если изменить индекс, получится другое вещество.

## 5. Что такое химическое уравнение

Химическая реакция записывается так:

```text
исходные вещества -> продукты реакции
```

Пример:

```text
H2 + O2 -> H2O
```

Но так запись еще не уравнена.

До реакции:

- H = 2;
- O = 2.

После реакции:

- H = 2;
- O = 1.

Кислород не совпадает. Нужно поставить коэффициенты:

```text
2H2 + O2 -> 2H2O
```

Проверка:

До реакции:

- H = 4;
- O = 2.

После реакции:

- H = 4;
- O = 2.

Теперь уравнение верное.

## 6. Алгоритм расстановки коэффициентов

1. Запиши схему реакции.
2. Посчитай атомы каждого элемента слева и справа.
3. Начинай с элемента, который встречается в меньшем числе веществ.
4. Ставь коэффициенты перед формулами.
5. Не меняй индексы в формулах.
6. В конце проверь все элементы.

## 7. Разбор примеров

### Пример 1

```text
Mg + O2 -> MgO
```

Слева кислорода 2, справа кислорода 1. Ставим 2 перед MgO:

```text
Mg + O2 -> 2MgO
```

Теперь справа магния 2, значит слева тоже нужен коэффициент 2:

```text
2Mg + O2 -> 2MgO
```

Проверка:

- Mg: слева 2, справа 2;
- O: слева 2, справа 2.

### Пример 2

```text
Al + Cl2 -> AlCl3
```

Хлор: слева 2, справа 3. Нужен общий счет 6:

```text
2Al + 3Cl2 -> 2AlCl3
```

Проверка:

- Al: слева 2, справа 2;
- Cl: слева 6, справа 6.

### Пример 3

```text
CaCO3 -> CaO + CO2
```

Считаем:

- Ca: слева 1, справа 1;
- C: слева 1, справа 1;
- O: слева 3, справа 1 + 2 = 3.

Уравнение уже уравнено:

```text
CaCO3 -> CaO + CO2
```

## 8. Практика вместе

Решить вместе с учеником, проговаривая каждый шаг.

### Задание 1

```text
Fe + S -> FeS
```

Ответ:

```text
Fe + S -> FeS
```

Коэффициенты не нужны, потому что атомы уже совпадают.

### Задание 2

```text
Na + Cl2 -> NaCl
```

Ответ:

```text
2Na + Cl2 -> 2NaCl
```

### Задание 3

```text
P + O2 -> P2O5
```

Ответ:

```text
4P + 5O2 -> 2P2O5
```

## 9. Самостоятельная мини-проверка

### Часть A. Состав формул

Определи количество атомов каждого элемента.

1. H2SO4
2. Ca(OH)2
3. Na2CO3
4. Fe2O3
5. Al2(SO4)3

### Часть B. Индекс или коэффициент

Объясни, что означает выделенная цифра.

1. 2H2O - первая цифра 2 перед формулой.
2. H2O - цифра 2 после H.
3. 3CO2 - цифра 3 перед формулой.
4. CO2 - цифра 2 после O.

### Часть C. Расставь коэффициенты

1. H2 + Cl2 -> HCl
2. K + O2 -> K2O
3. Fe + O2 -> Fe2O3
4. Al + O2 -> Al2O3
5. H2O2 -> H2O + O2

## 10. Ответы

### Часть A

1. H2SO4: H = 2, S = 1, O = 4.
2. Ca(OH)2: Ca = 1, O = 2, H = 2.
3. Na2CO3: Na = 2, C = 1, O = 3.
4. Fe2O3: Fe = 2, O = 3.
5. Al2(SO4)3: Al = 2, S = 3, O = 12.

### Часть B

1. 2H2O: коэффициент, означает 2 молекулы воды.
2. H2O: индекс, означает 2 атома водорода в одной молекуле воды.
3. 3CO2: коэффициент, означает 3 молекулы углекислого газа.
4. CO2: индекс, означает 2 атома кислорода в одной молекуле CO2.

### Часть C

1. H2 + Cl2 -> 2HCl
2. 4K + O2 -> 2K2O
3. 4Fe + 3O2 -> 2Fe2O3
4. 4Al + 3O2 -> 2Al2O3
5. 2H2O2 -> 2H2O + O2

## 11. Типичные ошибки и как исправлять

Ошибка: ученик меняет H2O на H2O2, чтобы "добавить кислород".

Как исправить: напомнить, что индекс меняет само вещество. В реакциях меняют только коэффициенты.

Ошибка: ученик забывает умножать скобки.

Как исправить: дать 3-4 формулы со скобками и считать их отдельно.

Ошибка: ученик ставит коэффициент, но не пересчитывает остальные атомы.

Как исправить: после каждого коэффициента заново считать левую и правую часть.
