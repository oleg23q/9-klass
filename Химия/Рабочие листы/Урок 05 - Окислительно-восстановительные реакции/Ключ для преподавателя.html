Задание 1. Ответ: K₂Cr₂O₇: Cr +6; KMnO₄: Mn +7; H₂SO₃: S +4; KClO₃: Cl +5; HClO₄: Cl +7

Найди степень окисления выделенного элемента: K₂Cr₂O₇ (Cr), KMnO₄ (Mn), H₂SO₃ (S), KClO₃ (Cl), HClO₄ (Cl).
  • Сумма степеней окисления в нейтральной молекуле равна 0; K +1, H +1, O −2.
Частые неверные ответы и ошибки: K₂Cr₂O₇: Cr +12 — А: не поделено на число атомов хрома; KMnO₄: Mn −7 — С: потерян знак

Задание 2. Ответ: Fe₂O₃ + 3CO → 2Fe + 3CO₂; Fe +3 → 0 (окислитель Fe₂O₃), C +2 → +4 (восстановитель CO); 6 электронов

Для реакции Fe₂O₃ + CO → Fe + CO₂ определи изменения степеней окисления, окислитель, восстановитель и расставь коэффициенты по электронному балансу.
  • Fe: +3 → 0, принимает 3ē, в Fe₂O₃ два атома — 6ē.
  • C: +2 → +4, отдаёт 2ē; нужно 3 молекулы CO для 6ē.
  • Итог: Fe₂O₃ + 3CO → 2Fe + 3CO₂.
Частые неверные ответы и ошибки: окислитель CO — П: окислитель и восстановитель перепутаны; коэффициенты 1, 1 → 2, 1 — У: электроны не уравнены

Задание 3. Ответ: 2H₂S + SO₂ → 3S + 2H₂O; восстановитель H₂S (S −2 → 0), окислитель SO₂ (S +4 → 0); 4 электрона

Для реакции H₂S + SO₂ → S + H₂O найди окислитель и восстановитель и расставь коэффициенты (сера есть и в одном, и в другом исходном веществе).
  • S⁻² − 2ē → S⁰ (×2), S⁺⁴ + 4ē → S⁰ (×1).
  • Число отданных электронов 2·2 = 4 равно числу принятых 4.
Частые неверные ответы и ошибки: окислитель H₂S — П: окислитель и восстановитель перепутаны; 2, 2 → 2, 2 — У: электронный баланс не использован

Задание 4. Ответ: ОВР: б) O −1 → −2 и 0; г) Na 0 → +1, Cl 0 → −1; не ОВР: а), в)

Какие из реакций являются окислительно-восстановительными? а) CaCO₃ → CaO + CO₂; б) 2H₂O₂ → 2H₂O + O₂; в) NaOH + HCl → NaCl + H₂O; г) 2Na + Cl₂ → 2NaCl. Для ОВР укажи, какие элементы меняют степень окисления.
  • Если степени окисления не меняются — реакция не ОВР.
  • В б) кислород и окисляется, и восстанавливается; в г) участвуют простые вещества — всегда ОВР.
Частые неверные ответы и ошибки: в) ОВР — К: реакция обмена не меняет степени окисления; а) ОВР — К: разложение принято за ОВР автоматически

Задание 5. Ответ: только окислитель — H₂SO₄ (по сере); только восстановитель — H₂S; зависят от партнёра — SO₂ и S

Какие из веществ H₂SO₄ (S +6), SO₂ (S +4), S (0), H₂S (S −2) могут быть только окислителями, только восстановителями, и в каких случаях роль зависит от партнёра?

Частые неверные ответы и ошибки: SO₂ только восстановитель — П: не учтено, что +4 — промежуточная степень
