# Окислительно-восстановительные реакции — интерактивный тренажёр

Автономная практика к уроку [[Урок 05 - Окислительно-восстановительные реакции]].

## Запуск

Откройте [index.html](index.html) в современном браузере. Интернет и установка не нужны.

## Что отрабатывается

- степени окисления в простых веществах и соединениях;
- связь «отдал электрон — окислился» и «принял электрон — восстановился»;
- различение окислителя и восстановителя;
- подбор множителей электронного баланса;
- расстановка коэффициентов в трёх простых ОВР;
- восемь заданий с мгновенной проверкой.

Материал подготовлен для занятия; прохождение тренажёра не считается подтверждением освоения без ответов ученика.
