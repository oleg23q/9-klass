# 9 КЛАСС — Тренажёр

Расширяемое Windows-приложение на C#/.NET 10 и WPF. Оно использует подготовленные ученические Markdown-уроки, показывает задания по шагам и хранит ответы отдельно от содержания. Текущая версия исходников — 0.2.

## Уже работает

- каталог физики, химии и информатики;
- 25 встроенных уроков и 224 последовательных шага;
- нативные графические схемы из Mermaid-блоков: цветные узлы, стрелки, подписи и развилки без подключения к интернету;
- читаемое представление Markdown-таблиц и используемых в уроках формул: без служебных `|---|`, `$`, `\\frac` и `\\qquad`;
- разбор каждого шага скрыт до ручного открытия или повторного входа в шаг с уже сохранённым ответом;
- учебный текст можно выделять по словам или фрагментами и копировать через `Ctrl+C` либо контекстное меню;
- режим «Развернуть урок» скрывает панели предметов и уроков и отдаёт материалу всю рабочую область; включается кнопкой или `F11`, выключается повторно либо клавишей `Esc`;
- отдельное поле ответа для каждого задания;
- кнопка раскрытия правильного разбора;
- отметка выполненных шагов и индикатор прогресса;
- автоматическое локальное сохранение ответов;
- импорт одного `.md` или ZIP с несколькими уроками;
- обновление урока без удаления ответов ученика.
- несколько локальных профилей учеников с раздельными ответами и прогрессом;
- встроенный редактор и проверка Markdown-уроков;
- экспорт и импорт ZIP-пакета прогресса с объединением более новых ответов.

## Запуск для разработки

```powershell
dotnet run --project .\src\Grade9Trainer.App\Grade9Trainer.App.csproj
```

Проверки:

```powershell
dotnet build .\Grade9Trainer.slnx
dotnet run --project .\tests\Grade9Trainer.SmokeTests\Grade9Trainer.SmokeTests.csproj
dotnet run --project .\tests\Grade9Trainer.UiSmoke\Grade9Trainer.UiSmoke.csproj -- .\artifacts\ui-smoke.png
```

Автономная сборка для передачи ученику:

```powershell
dotnet publish .\src\Grade9Trainer.App\Grade9Trainer.App.csproj -p:PublishProfile=StudentWin64 -o .\artifacts\publish-student-win64
```

Профиль `StudentWin64` встраивает нативные WPF-библиотеки внутрь EXE. Не копируйте из обычного publish только `Grade9Trainer.exe`: без расположенных рядом нативных DLL такая неполная сборка не запускается.

## Где хранятся данные

- встроенные уроки: папка `Lessons` рядом с программой;
- добавленные уроки: `%LOCALAPPDATA%\Grade9Trainer\Lessons`;
- ответы и прогресс: `%LOCALAPPDATA%\Grade9Trainer\progress.json`.
- список учеников: `%LOCALAPPDATA%\Grade9Trainer\profiles.json`;
- прогресс дополнительных учеников: `%LOCALAPPDATA%\Grade9Trainer\Students\<id>\progress.json`.

Формат нового материала описан в [Content/LESSON_FORMAT.md](Content/LESSON_FORMAT.md).

## Границы версии 0.2 и следующие этапы

- редактор работает с Markdown целиком; визуальные формы для шагов и схем ещё не добавлены;
- поддержан используемый в уроках поднабор Mermaid `flowchart TD/LR`, но не весь синтаксис Mermaid;
- математическое представление охватывает команды, встречающиеся во встроенных уроках, но не является полным движком LaTeX;
- обмен прогрессом выполняется вручную через ZIP; автоматическая синхронизация папки или облака ещё не включена;
- пока нет удаления, переименования и общей аналитики по ученикам;
- экспорт результатов ученика;
- миграция реализации хранилища прогресса на SQLite при росте объёма данных;
- безопасный запуск учебных программ Python в отдельной среде.
