УЧЕНИЧЕСКИЙ КОМПЛЕКТ «9 КЛАСС»
Сборка от 23.09.2026: тренажёры по законам Ньютона и задачи повышенной сложности по информатике

1. «9 класс — ученик» — готовое хранилище Obsidian с 18 уроками.
   Откройте эту папку в Obsidian как хранилище.
   Архив «9 класс — ученик.zip» предназначен для переноса на другой компьютер.

2. «Тренажёр на C#» — автономное Windows-приложение.
   Не запускайте его из ZIP. Откройте папку и запустите Grade9Trainer.exe.
   Для каждого ученика можно создать отдельный локальный профиль.

3. «Веб-тренажёр — первый закон Ньютона» — интерактивная практика к уроку физики 06.
   Откройте index.html двойным щелчком. Интернет для работы не нужен.
   Сначала сделайте прогноз, затем проверьте равнодействующую и решите шесть заданий.

4. «Веб-тренажёр — второй закон Ньютона» — интерактивная практика к уроку физики 07.
   Откройте index.html двойным щелчком. Интернет для работы не нужен.
   Исследуйте связь силы, массы и ускорения, затем решите шесть заданий.

5. «Веб-тренажёр — свободное падение» — интерактивная практика к уроку физики 08.
   Откройте index.html двойным щелчком. Интернет для работы не нужен.
   Сначала сделайте прогноз, затем запустите модель и решите шесть заданий.

6. «Веб-тренажёр — графы и матрицы» — дополнительная практика по информатике.
   Откройте index.html двойным щелчком. Интернет для работы не нужен.
   Сначала выполните задания ОГЭ, затем перейдите во вкладку «ЕГЭ — сложнее».

Новые тренажёры помогают:
- отличать нулевую равнодействующую от отсутствия сил;
- находить направление изменения скорости;
- вычислять равнодействующую и ускорение по второму закону Ньютона;
- считать пути в ориентированном графе методом подписей у вершин.

Правильные ответы и подсказки открывайте только после собственной попытки.
