# Формулы физики 7–9 класс

База данных формул: одна заметка на формулу, таблицы собирает [база](%D0%A4%D0%BE%D1%80%D0%BC%D1%83%D0%BB%D1%8B%20%D1%84%D0%B8%D0%B7%D0%B8%D0%BA%D0%B8.base). Папка: `Физика/Формулы физики/`.

Представления базы: «Все формулы», «7 класс», «8 класс», «9 класс», «По разделам», «Связаны с уроками», «С практикой». Формулы, которые изучают в двух классах, помечены двумя классами (например, `[7, 9]`) и показаны в обоих разделах.

## Задачи и уроки

В каждой формуле есть одна задача со скрытым решением (раскрывается кликом) и раздел «Уроки». Ссылки на уроки стоят только там, где формула реально разбирается в уроках 01–17 ([Физика - карта тем](../README.md)); у остальных формул уроков пока нет. Когда появятся новые уроки, добавьте ссылку в свойство `lessons` и в раздел «Уроки».

## Как добавлять формулу

1. Скопировать любую заметку из папки и изменить свойства `grade`, `section`, `formula`, `result_unit`.
2. Обозначения записывать таблицей «Величина — Что это — Единица СИ».
3. Условия применимости писать в раздел «Важно».

## Граница проверки

Формулы составлены по типовой программе 7–9 классов, а не по конкретному учебнику. Набор и обозначения могут отличаться от учебника ученика. Заметки ещё не проверены в Obsidian.
