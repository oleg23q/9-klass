# КПД механизма

$$\eta = \frac{A_{\text{полезн}}}{A_{\text{затр}}}\cdot 100\%$$

`η = A_полезн / A_затр · 100%`

## Обозначения

| Величина | Что это | Единица СИ |
| --- | --- | --- |
| η | КПД | % |
| A_полезн | полезная работа | Дж |
| A_затр | затраченная работа | Дж |

## Задача

Для подъёма груза совершили работу 1000 Дж, из них полезная 800 Дж. Найдите КПД.

> [!example]- Решение
> η = A_полезн / A_затр · 100% = 800/1000 · 100%
>
> **Ответ:** 80 %

## Уроки

В готовых уроках физики (01–10) эта формула пока не разбирается.

См. [Формулы физики](README.md).
