# Закон радиоактивного распада

$$N = N_0\cdot 2^{-t/T}$$

`N = N₀·2^(−t/T)`

## Обозначения

| Величина | Что это | Единица СИ |
| --- | --- | --- |
| N | число нераспавшихся ядер | — |
| N₀ | начальное число ядер | — |
| t | время | с |
| T | период полураспада | с |

## Задача

Период полураспада изотопа 5 суток. Сколько ядер из 1600 останется через 15 суток?

> [!example]- Решение
> t/T = 15/5 = 3, значит прошло 3 периода: N = N₀ / 2³ = 1600 / 8
>
> **Ответ:** 200 ядер

## Уроки

В готовых уроках физики (01–10) эта формула пока не разбирается.
