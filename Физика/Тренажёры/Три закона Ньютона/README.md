# Три закона Ньютона — интерактивный тренажёр

Автономный веб-тренажёр к уроку [[Урок 12 - Три закона Ньютона]]. Формат продолжает подход предыдущих тренажёров: краткая теория, управляемая модель, пошаговые разборы, алгоритм с калькулятором и задания с мгновенной проверкой.

## Запуск

Откройте файл [index.html](index.html) в современном браузере. Интернет, установка и сервер не нужны.

## Разделы

- **Теория** — три закона, силы третьего закона приложены к разным телам, алгоритм для нескольких тел.
- **Эксперимент** — две тележки расталкиваются пружиной; можно менять массы и силу толчка, предсказать ускорения, проверить прогноз и увидеть пару равных сил во время толчка и равномерное движение после него.
- **Разборы задач** — четыре подробные задачи (какой закон, несколько сил, две тележки, тела на нити); шаги открываются по одному.
- **Алгоритм** — четыре шага решения и калькулятор с подстановкой для четырёх типов задач.
- **Задания** — двенадцать задач с проверкой, подсказкой и полным разбором после первой попытки; результат сохраняется только в браузере.

## Учебный порядок

1. Пройти объяснение в уроке 12.
2. В эксперименте предсказать $a_1$ и $a_2$, проверить прогноз, затем изменить массы и силу.
3. Разобрать задачи и воспроизвести расчёт в калькуляторе.
4. Решить задания 1–12; после ошибки открыть подсказку, затем разбор и повторить.

Во всех расчётах $g=10\ \text{м/с}^2$, трения нет. Модель идеализирована и не заменяет реальный опыт. Готовый тренажёр не доказывает, что занятие проведено или тема освоена.
