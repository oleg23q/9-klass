# Первый закон Ньютона — интерактивный тренажёр

Автономная практика к уроку [[Урок 06 - Инерция и первый закон Ньютона]].

## Запуск

Откройте [index.html](index.html) в современном браузере. Интернет и установка не нужны.

## Что отрабатывается

- равнодействующая как сумма сил с учётом направления;
- условие первого закона: $F_{рез}=0$;
- покой как частный случай постоянной скорости;
- отличие отсутствия сил от их взаимной компенсации;
- прогноз движения до запуска модели;
- шесть заданий с подсказками и сохранением прогресса.

Материал подготовлен для занятия; прохождение тренажёра не считается подтверждением освоения без ответов ученика.
