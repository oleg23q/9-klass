# Движение по окружности — интерактивный тренажёр

Автономный веб-тренажёр к уроку [[Урок 10 - Движение тела по окружности с постоянной по модулю скоростью]]. Формат продолжает подход предыдущих тренажёров: краткая теория, управляемая модель, пошаговые разборы, алгоритм с калькулятором и задания с мгновенной проверкой.

## Запуск

Откройте файл [index.html](index.html) в современном браузере. Интернет, установка и сервер не нужны.

## Разделы

- **Теория** — период и частота, линейная и угловая скорость, центростремительное ускорение и сила, направления векторов.
- **Эксперимент** — тело движется по окружности; можно менять радиус, период и скорость показа, видеть скорость по касательной и ускорение к центру, проверить прогноз $v$ и $a$ и оборвать нить, чтобы увидеть полёт по касательной.
- **Разборы задач** — четыре подробные задачи (колесо, автомобиль на повороте, точка на ободе, стрелки часов); шаги открываются по одному.
- **Алгоритм** — четыре шага решения и калькулятор с подстановкой для трёх наборов исходных данных.
- **Задания** — двенадцать задач с проверкой, подсказкой и полным разбором после первой попытки; результат сохраняется только в браузере.

## Учебный порядок

1. Пройти объяснение в уроке 10.
2. В эксперименте предсказать $v$ и $a$, проверить прогноз и оборвать нить.
3. Разобрать задачи и воспроизвести расчёт в калькуляторе.
4. Решить задания 1–12; после ошибки открыть подсказку, затем разбор и повторить.

Во всех расчётах принято $\pi=3{,}14$. Модель показывает равномерное движение и не заменяет реальный опыт. Готовый тренажёр не доказывает, что занятие проведено или тема освоена.
