# Свободное падение — интерактивный тренажёр

Автономный веб-тренажёр к уроку [[Урок 08 - Свободное падение тел]]. Формат продолжает удачный подход тренажёра «Графы и матрицы»: короткая теория, наглядная модель, управляемый эксперимент, пошаговый алгоритм и задания с мгновенной проверкой.

## Запуск

Откройте файл [index.html](index.html) в современном браузере. Интернет, установка и сервер не нужны.

## Разделы

- короткая теория о модели свободного падения и формулах;
- интерактивное падение с выбранной высоты на Земле или Луне;
- сравнение тел разной массы;
- калькулятор с объяснением каждого шага;
- шесть заданий с проверкой, подсказками и сохранением результата в браузере.

## Учебный порядок

1. Пройти объяснение в уроке 08.
2. В симуляции предсказать время и скорость, затем запустить падение.
3. Сравнить тела массой 1 и 5 кг при одинаковых условиях.
4. Решить задания 1–6 без открытия подсказок; после ошибки разобрать алгоритм и повторить.

В расчётах тренажёр явно показывает принятое значение $g$. Модель не учитывает сопротивление воздуха и не заменяет реальный эксперимент.
