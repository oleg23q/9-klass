# Второй закон Ньютона — интерактивный тренажёр

Автономная практика к уроку [[Урок 07 - Сила, масса и второй закон Ньютона]].

## Запуск

Откройте [index.html](index.html) в современном браузере. Интернет и установка не нужны.

## Что отрабатывается

- расчёт равнодействующей с учётом направления;
- формула $a=F_{рез}/m$ и единицы СИ;
- связь ускорения с силой и массой;
- перевод граммов в килограммы;
- прогноз до вычисления и шесть заданий с проверкой.

Материал подготовлен для занятия; прохождение тренажёра не считается подтверждением освоения без ответов ученика.
