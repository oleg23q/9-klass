# Физика

Этот раздел для объяснений, задач, формул, квизов и повторения физики 9 класса.

## Что хранить здесь

- конспекты по темам;
- задачи с решениями;
- формулы и единицы измерения;
- ошибки ученика и разборы;
- проверочные работы и ответы.

## Основные темы

- движение, скорость, ускорение, графики;
- силы, масса, вес, законы Ньютона;
- импульс, работа, мощность, энергия;
- колебания, волны, звук;
- электромагнитные явления;
- атомная и ядерная физика.

## Быстрый запуск

```text
$grade9-physics-tutor объясни тему "Законы Ньютона" простым языком и дай 7 задач для проверки
```

```text
$grade9-physics-tutor реши задачу с оформлением Дано, переводом в СИ, формулой и проверкой единиц
```

```text
$grade9-physics-tutor сделай шпаргалку по формулам физики 9 класса
```
