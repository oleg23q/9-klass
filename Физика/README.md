# Физика

Этот раздел для объяснений, задач, формул, квизов и повторения физики 9 класса.

## Что хранить здесь

- конспекты по темам;
- задачи с решениями;
- формулы и единицы измерения;
- ошибки ученика и разборы;
- проверочные работы и ответы.

## Уроки

- [Урок 01. Материальная точка и система отсчета](Уроки/Урок%2001%20-%20Материальная%20точка%20и%20система%20отсчета.md)

## Учебник учителя

По фото ориентир: А. В. Перышкин, Е. М. Гутник, "Физика. 9 класс", Дрофа/Вертикаль.

Для занятий дома: держать названия уроков рядом с параграфами учителя. В начале физики не перегружать формулами, сначала отработать модель, тело отсчета и систему отсчета.

## Основные темы

- движение, скорость, ускорение, графики;
- силы, масса, вес, законы Ньютона;
- импульс, работа, мощность, энергия;
- колебания, волны, звук;
- электромагнитные явления;
- атомная и ядерная физика.
